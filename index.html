Jottem Open Data

Alles wat op het Jottem-platform wordt gepubliceerd is open data: per project een dataset (schema.org AP NDE) met RDF-dump en SPARQL-endpoint, IIIF Presentation-manifests en -collections, een Change Discovery activity-stream, W3C Web Annotations en RSS-feeds. Deze pagina bundelt alle uitgangen.

Broncode

Jottem is open source; alle repo’s staan op GitHub onder inside-out-time-machines.

  • jottem — github.com/inside-out-time-machines/jottem — het platform: backend-API (FastAPI), frontend (Next.js) en deployment
  • design — github.com/inside-out-time-machines/design — het ontwerp: requirements, architectuur, API-specificaties (gepubliceerd op design.iotm.nl)
  • data — github.com/inside-out-time-machines/data — deze open-data-pagina
  • brand — github.com/inside-out-time-machines/brand — de merkgids (gepubliceerd op brand.iotm.nl)
  • website — github.com/inside-out-time-machines/website — de IOTM-website (www.iotm.nl)
